# Zepto Homepage

This is a Zepto homepage clone that I created using React. It is inspired by the Zepto grocery delivery website.

## Features

- Responsive header with delivery location, search, login, and cart
- Promotional banner and hero sections
- Product category sections 
- Product cards using FakeStore API
- Laundry Care and other product sections
- Categories and Cities sections
- Footer with useful links and app download section
- Responsive design for desktop and mobile

## Technologies Used

- React.js
- React Bootstrap
- Axios
- Font Awesome
- HTML
- CSS

## API

I used the FakeStore API to display sample product data.

https://fakestoreapi.com/
